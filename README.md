# NEXUS OS

A Debian-based cybersecurity and development operating system with its own
desktop environment, **NEXUS HORIZON**.

> **Status: under active construction.** This README is replaced by the full
> project documentation as components land. See `docs/` for what exists today
> and — just as importantly — what has and has not been tested.

| | |
|---|---|
| Base | Debian 13 "trixie" (stable) |
| Architectures | amd64, arm64 |
| Desktop | NEXUS HORIZON (Wayland) |
| Licence | GPL-3.0-or-later (see `LICENSE`; third-party components keep their own licences) |
