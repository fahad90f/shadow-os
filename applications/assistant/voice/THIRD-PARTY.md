# Voice engine — third-party components

Nothing below is stored in the Shadow OS repository or the shadow-assistant package.
`shadow-voice-setup` downloads each file from its upstream release (pinned URL, size and
sha256), unpacks only what the engine loads and keeps the upstream licence texts in
`<data root>/licenses/`. Only permissively licensed components are used; no voice or
model with a non-commercial licence is downloaded.

| Component (installed path) | Upstream / version | Licence | Notes |
|---|---|---|---|
| sherpa-onnx Python runtime (`runtime/sherpa_onnx/`) | k2-fsa/sherpa-onnx 2.0.2, wheels `sherpa_onnx-2.0.2-cp312/cp313-manylinux2014_x86_64` + `sherpa_onnx_core-2.0.2-py3-none-manylinux2014_x86_64` from PyPI | Apache-2.0 | `licenses/sherpa-onnx/LICENSE` |
| ONNX Runtime (`runtime/sherpa_onnx/lib/libonnxruntime.so`, inside sherpa-onnx-core) | Microsoft onnxruntime (as built by k2-fsa) | MIT | |
| alsa-lib (`runtime/sherpa_onnx.libs/libasound-*.so`, bundled by auditwheel into the sherpa-onnx wheel) | ALSA project | LGPL-2.1-or-later | unmodified shared library, dynamically loaded; the engine itself never uses ALSA through it |
| numpy (`runtime/numpy/`, **only** when Debian's `python3-numpy` is not importable) | numpy 2.5.4 wheels cp312/cp313 from PyPI | BSD-3-Clause; bundled OpenBLAS BSD-3-Clause; libgfortran/libquadmath GPL-3.0-or-later **with the GCC Runtime Library Exception** | `licenses/numpy/LICENSE.txt` lists every bundled library |
| Silero VAD v4 (`models/vad/silero_vad.onnx`) | snakers4/silero-vad, file from the sherpa-onnx `asr-models` release | MIT | |
| Keyword spotter (`models/kws/`) | `sherpa-onnx-kws-zipformer-gigaspeech-3.3M-2024-01-01` (icefall zipformer trained on GigaSpeech XL by k2-fsa) | Apache-2.0 (model card) | `licenses/kws/README.md`; keywords file generated by the installer ("▁SHA D OW") |
| Moonshine base v2, English (`models/stt/moonshine/`) | Useful Sensors / Moonshine AI, `sherpa-onnx-moonshine-base-en-quantized-2026-02-27` | MIT for the English models (`licenses/moonshine/LICENSE`, section 1) | the same LICENSE file also contains the *Moonshine Community License* (non-commercial) — it applies only to the **non-English** Moonshine models, which are never downloaded |
| Whisper base.en int8 (`models/stt/whisper/`, optional) | OpenAI Whisper, converted to ONNX by k2-fsa (`sherpa-onnx-whisper-base.en`) | MIT (model), Apache-2.0 (conversion) | the archive ships no licence file; see `licenses/README` |
| Kokoro-82M v1.0 fp32 (`models/tts/kokoro/model.onnx`, `voices.bin`, `tokens.txt`) | hexgrad/Kokoro-82M, packaged by k2-fsa (`kokoro-multi-lang-v1_0`) | Apache-2.0 (`licenses/kokoro/LICENSE`) | all 54 voices of v1.0 are part of the Apache-2.0 release; the app offers only English voices |
| Kokoro lexicons (`lexicon-us-en.txt`, `lexicon-gb-en.txt`) | generated by k2-fsa from hexgrad/misaki's dictionaries | Apache-2.0 | |

Used at run time but installed by Debian, not by `shadow-voice-setup`:

| Program | Debian package | Licence | Why |
|---|---|---|---|
| `espeak-ng` | espeak-ng | GPL-3.0-or-later | pronunciation of words missing from the Kokoro lexicon (run as a separate process) |
| `pw-record` / `pw-play` | pipewire-bin | MIT | microphone capture / playback (preferred) |
| `parec` / `pacat` | pulseaudio-utils | LGPL-2.1-or-later | fallback capture / playback |
| `arecord` / `aplay` | alsa-utils | GPL-2.0-or-later | last-resort capture / playback |
| `python3`, `python3-numpy` | python3, python3-numpy | PSF-2.0, BSD-3-Clause | the helper's interpreter |

Code adapted into `shadow_voice/g2p.py`: the espeak-ng → misaki phoneme table (`E2M`) and the
function-word rules ("a", "the", "to") follow hexgrad/misaki (Apache-2.0).

Considered and **not** used: Piper voices (several are CC-BY-NC or have unclear dataset terms),
the Moonshine Community License models (non-commercial), Kitten/Pocket/Supertonic TTS
(evaluated in the voice lab; Kokoro sounded best at acceptable CPU cost).
